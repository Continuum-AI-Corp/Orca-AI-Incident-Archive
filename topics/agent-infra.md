**Common root causes**:
- Unauthenticated auto-login enabled by default (Langflow's `AUTO_LOGIN`)
- Binding to all network interfaces by default (OpenClaw)
- The "validation" function itself executes code (Langflow's `validate/code` evaluation decorator)
- No command sanitisation on the STDIO transport
- Maintainers treating the missing authentication as a "by-design trust model" (Ray)
