# Regional slices

The `region` field marks **where an event actually landed**. Cross-border vendor
vulnerabilities are always recorded as `GLOBAL` and never assigned to the
vendor's home country - otherwise the United States would be heavily
over-represented, which is the most common distortion in projects like this one.
