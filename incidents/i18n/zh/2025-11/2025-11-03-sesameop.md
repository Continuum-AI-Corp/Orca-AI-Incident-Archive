## 概要

Microsoft DART **2025-07** 在一起入侵响应中发现，11-03 公布。后门把 **OpenAI Assistants API 当 C2 通道**，指令藏在加密的 assistant description 里。微软强调**这不是漏洞或配置错误，而是对内置能力的滥用**；与 OpenAI 联合调查后封禁了相关 API key 与账号。（Assistants API 将于 2026-08 弃用）
