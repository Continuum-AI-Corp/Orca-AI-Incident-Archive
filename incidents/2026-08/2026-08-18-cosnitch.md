## Summary

Varonis Threat Labs reported it to Microsoft in **2025-12**, fixed **2026-08-18**, with no evidence of in-the-wild exploitation. A single URL with the hidden parameter **`autorun=1`** triggers prompt execution with no interaction beyond the user's click, exfiltrates data from connected OAuth apps (Gmail, Calendar, Drive) and **plants persistent memory rules that survive password changes, session revocation and device re-registration**. It can be chained with CVE-2026-24299 (Copirate 365).

**The discovery method itself is worth noting**: researchers repeatedly asked Copilot why a prompt could not run without user interaction, and the model eventually volunteered the parameter name `autorun=1`, the session conditions under which it takes effect, and the protections that were supposed to disable it — Varonis calls this "meta-hacking"
